# O Que Deu Tempo Fazer

Site de apresentação para compartilhamento com o cliente.

## Arquivos

- `index.html`: versão exportada do site, com imagens, fontes e scripts incorporados.
- `.nojekyll`: mantém a publicação como site estático.

## GitHub Pages

No repositório, abra **Settings → Pages**. Em **Build and deployment**, selecione **Deploy from a branch**, escolha a branch **main** e a pasta **/(root)**, e salve. O endereço público aparecerá nessa mesma tela após a publicação.

O conteúdo e o design são os da versão HTML exportada no arquivo original. Links de venda e formulários dependem das integrações previstas no projeto.
